# Incident-Response-Prototype

1. Download the Repository
   Download all files and directories contained in this repository and save them to a local directory of your choice.

2. Install Node.js and npm
   Ensure that Node.js (including npm) is installed on your system.
   Download: https://nodejs.org/en/download/

3. Navigate to the Project Directory
   Open a command line or terminal and navigate to the directory where you stored the project files.

4. Install Dependencies and Start the Development Server
   Run the following command to install all required dependencies and start the development server: "npm run dev"

5. Open the Application in Your Browser
   After successful startup, the terminal will display a local development address (e.g., http://localhost:5173/).
   Open this URL in your browser to access the prototype.
